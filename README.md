Design a modern, clean and professional SaaS web application UI for an “Education Center CRM System”.

The system is used by:
- Admin
- Teachers
- Students
- Parents

Main goal:
Help education centers manage students, groups, attendance, payments, homework, exams, and analytics in one system.

---

Create a dashboard-based UI with the following pages:

1. Authentication Pages
- Login
- Register
- Forgot password

2. Main Dashboard (Admin)
- Total students
- Active groups
- Monthly income
- Attendance percentage
- Debt students
- Charts (income & attendance)

3. Students Page
- Student list table
- Add/Edit student form
- Student profile page (with balance, attendance, payments)

4. Groups/Courses Page
- Course list
- Group creation
- Teacher assignment
- Schedule view

5. Attendance Page
- Calendar view
- Present / Absent / Late marking
- Filter by group

6. Payments Page
- Payment history table
- Debt tracking
- Add payment modal

7. Teacher Panel
- My groups
- Attendance marking
- Homework management

8. Parent Panel
- Child attendance
- Payments status
- Homework & results

---

Design style:
- Modern SaaS UI
- Clean layout
- Card-based design
- Minimal but powerful
- Use soft shadows and rounded corners
- Professional dashboard style like Stripe / Notion / Linear

---

Color palette:
- Primary: Blue / Indigo
- Background: White / Light gray
- Success: Green
- Warning: Orange
- Danger: Red

---

Typography:
- Modern sans-serif (Inter or similar)
- Clear hierarchy (H1, H2, body)

---

UX requirements:
- Easy navigation sidebar
- Responsive design (desktop first)
- Fast access to student and payment actions
- Clean tables with filters and search
- Modal-based forms

---

Overall feeling:
Professional SaaS product that can be sold to real education centers as a subscription system.
