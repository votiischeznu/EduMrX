A modern, clean, and professional **SaaS dashboard system** for education centers — built to manage students, groups, attendance, payments, homework, and exams in one unified platform.

---

## 👥 User Roles

| Role | Access |
|---|---|
| 🛠️ **Admin** | Full control — students, groups, payments, analytics |
| 👩‍🏫 **Teacher** | Group management, attendance, homework |
| 🎓 **Student** | Personal profile, homework, results |
| 👨‍👩‍👧 **Parent** | Child's attendance, payments, results |

---

## 🎯 Core Purpose

Help education centers manage the full learning-business lifecycle — students, groups, attendance, payments, homework, and exams — in a single, elegant system.

## 🎨 Design System

### Style Direction
Minimal, powerful, card-based layout with soft shadows and rounded corners — inspired by **Stripe**, **Notion**, and **Linear**.

### Color Palette

| Purpose | Color |
|---|---|
| 🔵 Primary | Blue / Indigo |
| ⚪ Background | White / Light Gray |
| 🟢 Success | Green |
| 🟠 Warning | Orange |
| 🔴 Danger | Red |

### Typography
- Font: **Inter** (or similar modern sans-serif)
- Clear visual hierarchy: `H1` → `H2` → Body text

---

## ⚡ UX Principles

- 🧭 Simple, intuitive sidebar navigation
- 💻 Responsive, desktop-first layout
- ⚡ Fast access to student & payment actions
- 🔍 Clean tables with filters and search
- 🪟 Modal-based forms for quick actions

---

## ✨ Vision

A polished, production-ready SaaS product — professional enough to be **sold as a subscription service** to real education centers.
